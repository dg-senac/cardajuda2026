Endereço do servidor

Este aplicativo guarda pacientes, médicos e consultas em um servidor. Informe o endereço onde o sistema está publicado para entrar.

Onde encontro esse endereço?

É o mesmo endereço que você abre no navegador do computador. Se o sistema já está publicado, ele se parece com https://cardiajuda.vercel.app.

Para testar com o servidor rodando na sua máquina, use o IP do computador com a porta: http://192.168.0.10:3000 (o celular precisa estar na mesma rede Wi-Fi).

Dica: se digitar só o domínio, o app completa com https://.
